## 🌕 풍요로운 한가위: 인터랙티브 웹페이지 ✨

> "더도 말고 덜도 말고 한가위만 같아라"

<br>

안녕하세요\! 한국의 아름다운 전통 명절인 \*\*한가위(추석)\*\*의 풍요롭고 따뜻한 분위기를 담아낸 인터랙티브 웹페이지 프로젝트입니다. Vue 3의 강력함과 CSS 애니메이션의 섬세함이 결합된 경험을 만나보세요\!

-----

### 🚀 프로젝트 개요 & 기술 스택

| 구분 | 내용 |
| :--- | :--- |
| **프로젝트 목표** | 한국 전통 명절 '한가위'의 정취를 구현하고 사용자 참여형 기능을 통합한 인터랙티브 웹페이지 제작 |
| **핵심 기능** | 동적인 야간 하늘 시각 효과, 사용자 덕담 게시판 |

-----

### 🌟 주요 구현 기능

#### 1\. 🌌 동적 & 몰입형 시각 효과 (Dynamic Visual Effects)

* **아름다운 야간 하늘:** CSS 애니메이션을 활용하여 반짝이는 별들, 유성(별똥별), 그리고 깊은 그라데이션이 적용된 밤하늘 배경을 구현하여 한가위의 감성을 극대화했습니다.
* **보름달 부유 애니메이션:** 순수 CSS `float` 키프레임 애니메이션을 적용해 보름달이 밤하늘에 자연스럽게 떠다니는 듯한 신비로운 효과를 연출했습니다.

#### 2\. 📝 사용자 참여형 콘텐츠: 덕담 나누기

* 사용자가 이름과 따뜻한 \*\*덕담(메시지)\*\*을 입력하고 제출할 수 있습니다.
* 제출된 덕담은 **최신순**으로 정렬되어 목록에 **실시간**으로 반영됩니다. 명절 인사와 소원을 공유하며 풍성한 소통의 장을 마련합니다.

#### 3\. 🖥️ 다중 플랫폼 호환성 (Responsive Design)

* 데스크톱, 태블릿, 모바일 등 **다양한 디바이스 해상도**에서 콘텐츠가 깨짐 없이 적절하게 표시되도록 반응형 스타일링을 완벽하게 적용했습니다.

본 웹페이지의 핵심 텍스트 콘텐츠(메인 카피, 메시지 카드, 전통 소개 등)는 Google의 **Gemini 모델**을 활용하여 생성되었습니다.

| 구분 | 프롬프트 요약 | 생성 결과 예시 (일부) |
| :--- | :--- | :--- |
| **메인 카피** | '풍요로운 한가위', '더도 말고 덜도 말고 한가위만 같아라' 포함 헤더 카피 생성 | **풍요로운 한가위** 더도 말고 덜도 말고 한가위만 같아라 |
