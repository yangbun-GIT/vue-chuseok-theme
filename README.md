1. 프로젝트 개요

본 프로젝트는 Vue 3, Vite, TypeScript 기술 스택을 기반으로 하여, 한국의 전통 명절인 한가위의 풍요로운 분위기를 구현한 인터랙티브 웹페이지입니다. 주요 시각적 요소로는 CSS 애니메이션을 통해 구현된 야간 하늘, 보름달, 유성(별똥별) 효과 등이 포함되며, 사용자가 직접 참여할 수 있는 덕담 게시 기능이 통합되었습니다.

2. 적용 기술 (Tech Stack)

Framework: Vue 3 (Composition API with <script setup>)

Bundler: Vite

Language: TypeScript

Styling: CSS (Scoped Styles)

Fonts: Google Fonts (Gowun Dodum)

3. 주요 구현 기능

동적 시각 효과: CSS 애니메이션을 활용하여 반짝이는 별, 유성, 그리고 그라데이션이 적용된 야간 하늘 배경을 구현했습니다.

CSS 기반 객체 애니메이션: float 키프레임 애니메이션을 통해 보름달이 자연스럽게 부유하는 효과를 연출했습니다.

사용자 참여형 콘텐츠: 사용자가 이름과 덕담을 입력하여 제출하면, 해당 내용이 최신순으로 정렬되어 목록에 실시간 반영되는 기능을 제공합니다.

다중 플랫폼 호환성: 데스크톱 및 모바일 환경 등 다양한 디바이스 해상도에서 콘텐츠가 적절히 표시되도록 반응형 스타일을 적용했습니다.

본 웹페이지에 사용된 주요 텍스트 콘텐츠는 Google의 Gemini 모델을 통해 생성되었으며, 활용된 프롬프트는 다음과 같습니다.

Prompt 2: 메시지 카드

Prompt 3: 전통 소개
